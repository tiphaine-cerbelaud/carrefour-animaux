# Carrefour Animaux — maquette interne

Maquette d'un site de services pour les propriétaires d'animaux (chiens, chats, nouveaux animaux de compagnie), sur le modèle de Carrefour Énergies.
**Usage interne uniquement** : offres, prix et partenaires sont fictifs.

## Contenu

- `index.html` — accueil : univers de besoins, sélecteur d'animal, fidélité, partenaires, conseils, FAQ
- `alimentation.html` — exemple de page univers, avec simulateur de ration et sélection produits
- `css/style.css` — styles (couleurs dans `:root`)
- `js/main.js` — menu mobile, sélecteur d'animal, simulateur
- `assets/logo-carrefour.svg` — **logo temporaire, à remplacer par le logo officiel** (même nom de fichier)

## Voir la maquette

Ouvrir `index.html` dans un navigateur. Aucune installation nécessaire.
